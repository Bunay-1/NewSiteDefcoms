# DefComs Website

Модерен, изключително сигурен и оптимизиран уебсайт за киберсигурност, изграден с Next.js 14, TypeScript, TailwindCSS и Prisma.

## Технологичен стек

- **Next.js 14** - React framework с App Router
- **TypeScript** - Type-safe разработка
- **TailwindCSS** - Utility-first CSS framework
- **Prisma ORM** - Модерен интерфейс за работа с бази данни
- **SQLite** - Локална релационна база данни за улеснена интеграция и бързина
- **NextAuth.js / Auth.js (v5)** - Сигурна аутентификация на сесиите
- **Bcrypt.js** - Криптографско хеширане на потребителски пароли
- **Lucide React** - Икони
- **Recharts** - Диаграми и аналитични чартове
- **Framer Motion** - Интерактивни анимации

## Инсталация и конфигуриране

1. **Инсталирайте зависимостите**:
```bash
npm install
```

2. **Конфигурирайте базата данни (Prisma)**:
   Приложете схемата върху SQLite базата данни и генерирайте Prisma Client:
```bash
npx prisma db push
```

3. **Заредете начални тестови данни (Seeding)**:
   Създайте автоматично базов тестов клиентски акаунт:
```bash
npx tsx scripts/seed.ts
```
   *Тестови акаунт за достъп:*
   - **Имейл:** `test@defcoms.eu`
   - **Парола:** `password123`

4. **Стартирайте development сървъра**:
```bash
npm run dev
```
   Отворете [http://localhost:3000](http://localhost:3000) в браузъра си.

## Клиентски портал (Client Portal)

Порталът на DefComs осигурява защитена среда за клиентите, чрез която те могат да комуникират с нашите анализатори по сигурността.

### Основни функционалности:
- **Регистрация на потребители** - Сигурно създаване на профил с валидация за съвпадение на пароли, уникален имейл и допълнителни фирмени данни.
- **Вход в системата** - Аутентификация през NextAuth v5 с JWT защитени сесии.
- **Информационно табло (Dashboard)** - Интерактивен преглед на статистика за отворени, обработващи се и решени тикети.
- **Система за тикети (Support Tickets)** - Възможност за отваряне на нов тикет с различен приоритет (Нисък, Среден, Висок, Спешен) и подробно описание на инцидент или запитване.
- **Интерактивен чат (Ticket Messages)** - Пълна нишка от съобщения в реално време между клиента и екипа за сигурност на DefComs с автоматично каскадно изтриване при премахване на профил.

## Тестване и проверка на функционалността

За осигуряване на максимална надеждност на уебсайта е разработен скрипт за пълна автоматизирана интеграционна проверка на портала.

Скриптът тества следните стъпки изолирано:
1. Регистрация на нов клиент в базата данни.
2. Проверка за уникалност на имейл адреса (блокиране на дублиран имейл).
3. Проверка на правилното криптографско хеширане на паролата с `bcrypt`.
4. Създаване на тестов тикет за сигурност.
5. Изпращане на тестови съобщения към тикета.
6. Сигурно почистване (Clean up) на тестовите данни от базата с валидация за референциален интегритет (`onDelete: Cascade`).

За да стартирате теста, изпълнете:
```bash
npx tsx scripts/test-portal.ts
```

## Структура на проекта

```
src/
├── app/
│   ├── api/                 # API Routes (Аутентификация, Регистрация, Тикети)
│   ├── compliance/          # Страница за съответствие с EU директиви
│   ├── portal/              # Клиентски портал (Dashboard, Вход, Регистрация, Тикети)
│   ├── products/            # Продукти (SOC Platform, SIEM и др.)
│   ├── services/           # Услуги по киберсигурност
│   ├── team/               # Екип на DefComs
│   ├── layout.tsx          # Основен Root layout на приложението
│   ├── page.tsx            # Начална целева страница
│   ├── globals.css         # Глобални стилове
│   ├── robots.txt          # SEO - Robots.txt
│   └── sitemap.ts          # SEO - Sitemap генератор
├── components/              # Преизползваеми UI компоненти (Чатбот, Навигация, Бисквитки)
├── lib/                     # Библиотеки (Prisma инстанция, NextAuth конфигурация)
└── generated/               # Автоматично генериран Prisma Client
scripts/                     # Административни скриптове (Seed, Интеграционен тест)
prisma/                      # Prisma схема и SQLite база данни
```

## SEO Оптимизация

Сайтът е оптимизиран за AI обхождане с:
- Structured data (Schema.org / JSON-LD) за Организация, Често задавани въпроси (FAQ) и Хлебни трохи (Breadcrumbs).
- Динамичен Sitemap.xml и Robots.txt.
- Open Graph мета тагове за социални мрежи.
- Семантичен HTML и бързо време за зареждане.
